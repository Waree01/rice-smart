# Knowledge Base Assets

This directory contains the Thai rice farming knowledge base files
used by the RAG system for Pasadee chatbot responses.

## Expected Files

- `best_practices.json` - Traditional Thai rice farming best practices
- `disease_guide.json` - Rice disease identification and treatment guide
- `pest_guide.json` - Common rice pests and management strategies
- `seasonal_calendar.json` - Rice growing calendar by region

## Data Sources

- Expert farmer consultation (field research)
- Thai Rice Department publications
- Local agricultural extension offices
